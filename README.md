
# University Management System

## A modular University Management System built with core Python, serving as a hands-on foundation for learning backend engineering concepts like SQL databases and authentication. .
## Features
   - Student Management
   - Teacher management
   - Course management
   - Department management
   - University statistics
   - Student and teacher searching
   - Student sorting by ID 
   - Custom exceptions 
   - Modular project structure

## Technologies Used
   - Python 
   - Object-Oriented Programming (OOP)
   - Custom Exceptions 
   - Modules 
   - Git & GitHub
